# Documentación

Documentación del proyecto universitario de gestión de proyectos informáticos para Magic Leaf Studios.

## Estructura

1. [`01_Documentos_Base/`](01_Documentos_Base/) contiene la información institucional, objetivos, alcances, riesgos, calidad y estabilidad. El plan de sustentabilidad se entrega también como [`Plan de Sustentabilidad.docx`](../Plan%20de%20Sustentabilidad.docx).
2. [`02_Diagramas/`](02_Diagramas/) contiene los diagramas del proyecto y de la organización, incluido el [diagrama financiero de BREAKTHROUGH](02_Diagramas/An%C3%A1lisis%20de%20Ganancias%20por%20Mes.pdf).
3. [`03_Manuales_de_Funciones/`](03_Manuales_de_Funciones/) contiene los manuales de funciones por área.
4. [`04_Manuales_de_Actividades/`](04_Manuales_de_Actividades/) contiene los manuales de actividades por área.
5. [`05_Analisis_Financiero/`](05_Analisis_Financiero/) contiene las hojas de cálculo y sus exportaciones PDF.
Los archivos editables y los PDF específicos se conservan junto a su categoría para facilitar la edición y la entrega final.
