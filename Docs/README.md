# Documentación

Documentación del proyecto universitario de gestión de proyectos informáticos para Magic Leaf Studios.

## Estructura

1. [`01_Documentos_Base/`](01_Documentos_Base/) contiene la información institucional, objetivos, alcances, riesgos, calidad, cumplimiento y sustentabilidad.
2. [`02_Diagramas/`](02_Diagramas/) contiene el [Gantt del Prototipo](02_Diagramas/Cronograma%20Gantt%20del%20Prototipo.pdf), el [diagrama financiero](02_Diagramas/An%C3%A1lisis%20de%20Ganancias%20por%20Mes.pdf), los [sprints del primer Prototipo](02_Diagramas/Sprints%20del%20Primer%20Prototipo.md) y el índice de [cronogramas](02_Diagramas/Cronogramas%20del%20Prototipo.md). Los diagramas PDF anteriores se conservan en [`Referencias/Diagramas/`](Referencias/Diagramas/).
3. [`03_Manuales_de_Funciones/`](03_Manuales_de_Funciones/) contiene los manuales de funciones por área.
4. [`04_Manuales_de_Actividades/`](04_Manuales_de_Actividades/) contiene los manuales de actividades por área.
5. [`05_Analisis_Financiero/`](05_Analisis_Financiero/) contiene el análisis de costos en Markdown, la hoja de cálculo original y sus exportaciones PDF.
